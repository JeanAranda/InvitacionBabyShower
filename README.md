# 🍼 Baby Shower de Antonella – Invitación Web

¡Bienvenido/a! Este es un proyecto de invitación digital para el **Baby Shower de Antonella**. Ha sido diseñado pensando en una experiencia dulce, moderna y con detalles animados para compartir con familiares y amigos.

---

## 📋 Descripción

Esta página web es una invitación interactiva que incluye:

- **Diseño temático** con tonos pasteles y una conejita animada.
- **Fondo con movimiento** (burbujas flotantes suaves).
- **Cuenta regresiva automática** hasta el día del evento.
- **Mapa integrado** para indicar la ubicación.
- **Formulario de confirmación** (enlace directo a WhatsApp y formulario local para registro).
- **Sección de regalos** con espacio para código QR.
- **Reproductor de música** de fondo.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – Estructura del contenido.
- **CSS3** – Estilos visuales, animaciones y efectos.
- **JavaScript** – Cuenta regresiva dinámica.
